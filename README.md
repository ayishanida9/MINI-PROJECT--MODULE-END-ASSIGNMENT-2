## POWER BI-DATA VISUALIZATION AND REPORT BUILDING

## Power BI Dashboard

### Overview
Created an interactive HR Analytics Dashboard using Microsoft Power BI to analyze employee attrition and identify workforce trends.

### Key Performance Indicators (KPIs)
- Total Employees
- Attrition Count
- Attrition Rate
- Average Age

### Visualizations
The dashboard includes eight visualizations analyzing attrition by:
- Gender
- Marital Status
- Job Role
- Overtime
- Department
- Age Group
- Education Field
- Years at Company

### Interactive Features
Added slicers for Department, Gender, and Job Role to dynamically filter the dashboard and explore attrition patterns.

### Skills Demonstrated
- Data visualization using Power BI
- DAX calculations
- KPI creation
- Interactive dashboard development
- Data analysis and reporting
